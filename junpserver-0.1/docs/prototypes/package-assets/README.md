# 基础安装包资产管理 4 张原型

这 4 张原型按 `DESIGN.md` 的设计契约拆分，避免重复：

1. `01-user-package-list.html`：普通用户“我的安装包资产”列表页。
2. `02-package-detail-drawer.html`：从列表打开的安装包详情抽屉。
3. `03-package-create-edit-drawer.html`：新增/编辑安装包复用抽屉。
4. `04-admin-user-asset-management.html`：Admin 用户与资产归属管理页。

打开方式：用浏览器直接打开对应 HTML。

说明：PNG 截图目录预留在 `png/`；当前环境缺少浏览器二进制，未能自动导出 PNG。
