## 1. 产品简介

### 1.1 OpsPaw 是什么

OpsPaw 是一个运维自动化平台，通过 AI Agent 结合 JumpServer 实现受控的命令执行和审批流程。面向试点团队提供任务创建、执行编排、风控审批、审计追溯等能力。

### 1.2 核心价值

- **安全可控**：命令黑名单策略评估、多级审批流、审计日志追溯
- **自动化执行**：模板化任务创建、批量重试、失败分型
- **可解释性**：失败根因分析、修复建议、执行样本查看

### 1.3 适用角色

| 角色 | 职责 | 权限 |
|------|------|------|
| 操作员 | 创建任务、查看执行结果 | 任务创建、查看审计 |
| 审批人 L1 | 一级审批决策 | 通过/驳回/升级 |
| 审批人 L2 | 二级审批决策（高风险任务） | 通过/驳回 |
| 管理员 | 配置管理、策略治理 | 全部权限 |

## 2. 快速开始

### 2.1 访问地址

部署成功后，访问：

- **前端界面**：`http://<服务器地址>/`
- **API 文档**：`http://<服务器地址>/docs`
- **健康检查**：`http://<服务器地址>/health`

### 2.2 登录说明

OpsPaw 使用 JumpServer 统一认证，无需单独注册账号。

1. 打开浏览器访问系统地址
2. 点击「使用 JumpServer 账号登录」
3. 输入 JumpServer 账号密码
4. 登录成功后自动跳转至 Dashboard

### 2.3 首次使用检查清单

- [ ] 确认 JumpServer 连接配置正确
- [ ] 确认已同步资产和系统用户
- [ ] 确认审批人角色已配置
- [ ] 确认命令黑名单策略已启用

## 3. 功能模块

### 3.1 Dashboard 看板

**路径**：首页 / Dashboard

**功能说明**：

Dashboard 展示系统整体健康度和执行统计，帮助快速了解系统状态。

**页面元素**：

1. **告警等级条**：显示当前系统健康状态（ok/warn/critical）
2. **失败分型榜单**：按失败次数排序的失败类型统计
3. **修复建议卡片**：针对高频失败类型的推荐修复步骤

**操作步骤**：

1. 访问 Dashboard 页面
2. 查看告警等级条颜色（绿色=正常，黄色=警告，红色=严重）
3. 点击失败分型卡片，跳转至失败详情页

---

### 3.2 失败详情页

**路径**：`/failures/{failure_code}`

**功能说明**：

查看特定失败类型的详细分析，包括根因、修复建议、失败样本。

**页面元素**：

1. **失败码标题**：失败类型名称和严重级别
2. **摘要说明**：失败原因简述
3. **推荐修复步骤**：分步骤的修复指南
4. **验证步骤**：修复后的验证方法
5. **失败样本表格**：近期失败任务列表

**筛选功能**：

- **时间范围**：选择查看最近 1/6/12/24 小时
- **来源筛选**：按任务来源过滤

**操作步骤**：

1. 从 Dashboard 点击失败分型卡片，或手动输入失败码
2. 查看修复建议和验证步骤
3. 根据建议进行修复
4. 在样本表格中查看具体失败任务

---

### 3.3 模板中心

**路径**：`/templates`

**功能说明**：

管理运维命令模板，支持新建、编辑、启停操作。

**页面元素**：

1. **模板列表**：展示所有模板及其状态
2. **新建按钮**：打开新建模板弹窗
3. **启停开关**：快速启用/禁用模板

**表单字段**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 模板 ID | 是 | 唯一标识，如 `nginx-restart` |
| 模板名称 | 是 | 人类可读名称，如 `Nginx 重启` |
| 描述 | 否 | 模板用途说明 |
| 命令内容 | 是 | 实际执行的 shell 命令 |
| 风险等级 | 是 | low/medium/high/critical |

**操作步骤 - 新建模板**：

1. 点击「新建模板」按钮
2. 填写表单字段
3. （可选）点击「策略评估」预览是否命中黑名单
4. 点击「提交」保存

**操作步骤 - 启停模板**：

1. 在模板列表找到目标模板
2. 切换「启用」开关
3. 禁用的模板无法在任务创建时选择

---

### 3.4 策略治理页

**路径**：`/policies`

**功能说明**：

管理命令黑名单策略，配置哪些命令被禁止执行。

**页面元素**：

1. **黑名单列表**：展示所有黑名单规则
2. **新增规则**：添加新的拦截规则
3. **实时评估**：输入命令预览是否被拦截

**操作步骤 - 新增黑名单**：

1. 点击「新增规则」按钮
2. 填写规则模式（支持正则）
3. 选择匹配类型（精确/正则/包含）
4. 填写拦截原因说明
5. 点击「提交」保存

**操作步骤 - 策略评估预览**：

1. 在命令输入框中输入待评估命令
2. 系统自动调用评估接口
3. 查看是否被拦截及匹配的规则

---

### 3.5 审批中心

**路径**：`/approvals`

**功能说明**：

处理待审批任务，支持通过/驳回/升级操作。

**页面元素**：

1. **Tab 切换**：L1 审批 / L2 审批
2. **待审批列表**：当前需审批的任务
3. **审批详情**：任务信息和决策区

**审批操作**：

| 操作 | 说明 | 限制 |
|------|------|------|
| 通过 | 批准任务执行 | 需填写审批意见 |
| 驳回 | 拒绝任务申请 | 需填写驳回原因 |
| 升级 | 升级至上一级审批 | 高风险任务需要 L2 审批 |

**操作步骤**：

1. 在待审批列表选择任务
2. 查看任务详情（命令内容、目标资产、风险等级）
3. 选择通过/驳回/升级
4. 填写审批意见
5. 点击「确认」提交决策

**超时机制**：

- 审批请求在 24 小时内有效
- 超时后审批按钮禁用，需重新提交任务

---

### 3.6 任务创建

**路径**：`/tasks/create`

**功能说明**：

创建运维任务，支持选择模板或手动输入命令。

**页面元素**：

1. **模板选择器**：下拉选择已启用的模板
2. **命令输入框**：手动输入命令（可选）
3. **目标资产**：选择执行任务的服务器
4. **系统用户**：选择执行身份
5. **策略预览**：实时显示评估结果

**必填字段**：

- 目标资产 ID（target_asset_id）
- 系统用户 ID（run_as_system_user_id）
- 模板或命令（二选一）

**操作步骤**：

1. 选择模板或输入命令
2. 选择目标资产
3. 选择系统用户
4. 查看策略评估结果
5. 点击「提交」创建任务

**提交后行为**：

- **无需审批**：跳转任务详情页查看执行状态
- **需要审批**：跳转审批详情页等待审批

---

### 3.7 治理审计

**路径**：`/audits`

**功能说明**：

查询配置变更和任务执行的审计日志。

**页面元素**：

1. **审计列表**：按时间倒序展示审计记录
2. **筛选条件**：实体类型/操作类型/操作人
3. **详情展开**：查看完整 JSON 详情

**筛选条件**：

| 条件 | 选项 | 说明 |
|------|------|------|
| 实体类型 | task/policy/template | 任务/策略/模板 |
| 操作类型 | create/update/delete/execute | 操作类型 |
| 操作人 ID | 用户 ID | 操作人标识 |

**操作步骤**：

1. 设置筛选条件（可选）
2. 查看审计列表
3. 点击记录展开 JSON 详情
4. 查看操作时间、操作人、变更内容

## 4. 常见问题

### 4.1 如何创建第一个任务

1. 访问模板中心，确认有可用模板
2. 访问任务创建页，选择模板
3. 选择目标资产和系统用户
4. 提交后根据风险等级判断是否需要审批

### 4.2 审批流程说明

| 风险等级 | 审批层级 | 流程 |
|----------|----------|------|
| Low | 无需审批 | 直接执行 |
| Medium | L1 审批 | 1 人批准即可执行 |
| High | L1 + L2 审批 | 2 人批准后方可执行 |
| Critical | L1 + L2 审批 | 2 人批准，建议人工复核 |

### 4.3 如何查看失败原因

1. 访问 Dashboard，查看失败分型榜单
2. 点击对应失败类型卡片
3. 在失败详情页查看根因分析和修复建议
4. 查看失败样本表格了解具体情况

### 4.4 如何添加新资产

资产同步由 JumpServer 管理：

1. 在 JumpServer 添加资产
2. 在 OpsPaw 策略治理页触发增量同步
3. 等待同步完成（约 1-2 分钟）
4. 在任务创建时即可选择新资产

### 4.5 命令被拦截怎么办

1. 查看拦截原因和匹配的规则
2. 如确需执行，联系管理员调整黑名单策略
3. 或手动在 JumpServer 执行（无审计）
