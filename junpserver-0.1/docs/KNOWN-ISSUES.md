## 文档说明

### 问题严重等级定义

| 等级 | 名称 | 定义 | 响应时限 |
|------|------|------|----------|
| P0 | 阻塞性 | 系统无法使用，核心功能失效 | 立即修复 |
| P1 | 严重 | 主要功能受影响，有替代方案 | 24 小时内 |
| P2 | 一般 | 功能瑕疵，不影响主要流程 | 3 天内 |
| P3 | 轻微 | 体验优化， cosmetic 问题 | 排期修复 |

### 问题状态定义

| 状态 | 说明 |
|------|------|
| 待修复 | 问题已确认，等待修复 |
| 修复中 | 已有 PR 或正在修复 |
| 已修复 | 问题已解决，待验证 |
| 延后 | 暂缓修复，放入后续版本 |

## 问题报告流程

### 如何报告新问题

1. 在内部 IM @OpsPaw-Support 或发送邮件至 ops-support@example.com
2. 提供以下信息：
   - 问题现象描述
   - 复现步骤
   - 截图或日志
   - 发生时间和频率
3. 问题确认后更新至此清单

### 问题修复流程

1. 开发者认领问题并创建修复分支
2. 完成修复后提交 PR
3. Code Review 通过后合并至 main
4. 更新问题状态为「已修复」
5. 验证通过后关闭问题
