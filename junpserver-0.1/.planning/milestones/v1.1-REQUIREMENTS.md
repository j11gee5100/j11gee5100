# Requirements: OpsPaw v1.1 前端联调（归档）

**Defined:** 2026-04-06
**Shipped:** 2026-04-10
**Core Value:** 提供安全可控的自动化执行闭环，让运维团队能快速响应告警和变更需求

---

## v1 Requirements - All Completed

### Dashboard 看板

- [x] **DASH-01**: 页面加载时调用 `GET /api/v1/dashboard/overview` 展示健康度 ✅
- [x] **DASH-02**: 显示告警等级条（alert level: ok/warn/critical）✅
- [x] **DASH-03**: 显示失败分型榜单（by_failure_code 排序）✅
- [x] **DASH-04**: 点击失败分型卡片跳转到失败详情页 ✅
- [x] **DASH-05**: 显示修复建议卡片（remediation_cards）✅

### 失败详情页

- [x] **FAIL-01**: 调用 `GET /api/v1/dashboard/failures/{failure_code}/detail` 加载详情 ✅
- [x] **FAIL-02**: 显示失败码标题、严重级别、摘要 ✅
- [x] **FAIL-03**: 显示推荐修复步骤和验证步骤 ✅
- [x] **FAIL-04**: 底部表格显示近期失败样本 ✅
- [x] **FAIL-05**: 支持按 hours/source 筛选刷新 ✅

### 模板中心

- [x] **TMPL-01**: 调用 `GET /api/v1/templates/commands` 显示模板列表 ✅
- [x] **TMPL-02**: 弹窗新建模板（POST /api/v1/templates/commands）✅
- [x] **TMPL-03**: 列表支持启停模板（PATCH enabled 字段）✅
- [x] **TMPL-04**: 表单包含 template_id/name/description/command/risk_level ✅
- [x] **TMPL-05**: 新建模板前调用策略评估预览 ✅

### 策略治理页

- [x] **POL-01**: 调用 `GET /api/v1/policies/command-blacklist` 显示黑名单列表 ✅
- [x] **POL-02**: 支持新增黑名单规则（POST）✅
- [x] **POL-03**: 支持修改规则（PATCH）✅
- [x] **POL-04**: 命令输入框实时调用 `POST /api/v1/policies/evaluate` 预览 ✅
- [x] **POL-05**: 被拦截时显示 block_reason 和 matched_rules ✅
- [x] **POL-06**: 调用 `GET /api/v1/governance/audits` 显示审计日志 ✅

### 审批中心

- [x] **APP-01**: 调用 `GET /api/v1/approvals/pending?current_level=N` 显示待审批列表 ✅
- [x] **APP-02**: 支持按 L1/L2 层级切换 Tab ✅
- [x] **APP-03**: 审批详情页显示基础信息、决策区、时间线 ✅
- [x] **APP-04**: 支持通过操作（POST /approve）✅
- [x] **APP-05**: 支持驳回操作（POST /reject）✅
- [x] **APP-06**: 支持升级操作（POST /escalate，受限 max_level）✅
- [x] **APP-07**: 超时状态禁用操作按钮 ✅

### 任务创建页

- [x] **TSK-01**: 选择模板或输入命令创建任务 ✅
- [x] **TSK-02**: 必填 target_asset_id 和 run_as_system_user_id ✅
- [x] **TSK-03**: 提交前调用策略评估预览 ✅
- [x] **TSK-04**: 提交后根据 approval_required 跳转审批页或任务详情 ✅
- [x] **TSK-05**: 命中策略拦截时禁用提交 ✅

### 治理审计页

- [x] **AUD-01**: 调用 `GET /api/v1/governance/audits` 显示审计列表 ✅
- [x] **AUD-02**: 支持按 entity_type/action/operator_id 筛选 ✅
- [x] **AUD-03**: 支持展开 detail JSON 查看详情 ✅
