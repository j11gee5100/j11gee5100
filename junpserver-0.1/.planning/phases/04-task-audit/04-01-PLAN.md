  <action>
    创建任务相关类型定义和 hooks。

    **类型定义 (frontend/src/types/task.ts):**
    - TaskCreateRequest 接口：
      - command_template_id?: string (可选，推荐)
      - command?: string (可选，模板为空时可填)
      - target_asset_id: string (必填)
      - run_as_system_user_id: string (必填)
      - risk_level?: 'low' | 'medium' | 'high' (默认 'medium')
      - idempotency_key?: string (可选)
    - TaskCreateResponse 接口：
      - task_id: string
      - approval_required: boolean
      - approval_id?: string (当 approval_required=true 时返回)

    **任务创建 Hook (frontend/src/hooks/useTasks.ts):**
    - 导入 useMutation, useQueryClient, apiClient
    - useCreateTask mutation hook：
      - mutationFn: POST /api/v1/tasks
      - 成功时不 invalidate（因为跳转页面）
      - 错误处理返回标准 ApiError

    **资产查询 Hook (frontend/src/hooks/useAssets.ts):**
    - useAssets hook：
      - 查询 GET /api/v1/assets
      - 返回 Asset[] 类型
      - staleTime: 60000

    Asset 类型定义（在 frontend/src/types/task.ts 或新建 asset.ts）：
    - asset_id: string
    - hostname: string
    - ip: string
    - status: string

    **系统用户查询 Hook (frontend/src/hooks/useSystemUsers.ts):**
    - useSystemUsersByAsset(assetId: string) hook：
      - 查询 GET /api/v1/assets/{asset_id}/system-users
      - 返回 SystemUser[] 类型
      - enabled: assetId 有值时才查询（条件查询）

    SystemUser 类型定义：
    - system_user_id: string
    - name: string
    - username: string
  </action>

    创建 TaskCreatePage 组件，实现基础表单布局和字段选择功能。

    **页面布局 (frontend/src/pages/TaskCreatePage.tsx):**
    - 导入必要的 Ant Design 组件：Form, Input, Select, Button, Typography, Card, Space
    - 导入 hooks：useTemplates, useAssets, useSystemUsersByAsset
    - 导入类型：Template, Asset, SystemUser, TaskCreateRequest
    - 页面标题：Typography.Title level={3} "创建任务"

    **表单字段：**
    1. 任务来源选择区（Radio.Group）：
       - options: [{ value: 'template', label: '选择模板' }, { value: 'custom', label: '自定义命令' }]
       - 默认值: 'template'

    2. 模板选择字段（当 source='template' 时显示）：
       - 使用 Select 组件，支持搜索过滤：showSearch, filterOption
       - 字段名：command_template_id
       - label: "选择模板" + 红色星号（必填标记 per D-02）
       - 选择后显示模板的风险等级标签（使用 RiskBadge）
       - options 从 useTemplates() 获取

    3. 自定义命令字段（当 source='custom' 时显示）：
       - 使用 Input.TextArea 组件
       - 字段名：command
       - label: "命令内容" + 煤色星号
       - placeholder: "输入要执行的命令"

    4. 命令预览区（始终显示）：
       - 显示当前命令内容（从模板填充或自定义输入）
       - 选择模板后自动填充，只读状态 per D-03

    5. 资产选择字段：
       - 使用 Select 组件，支持搜索 per D-04
       - 字段名：target_asset_id
       - label: "目标资产" + 红色星号（必填）
       - showSearch, filterOption
       - options 从 useAssets() 获取：以 hostname/IP 显示
       - 选择后触发系统用户查询（useSystemUsersByAsset）

    6. 系统用户选择字段：
       - 使用 Select 组件 per D-05
       - 字段名：run_as_system_user_id
       - label: "系统用户" + 红色星号（必填）
       - 未选择资产时 disabled
       - options 从 useSystemUsersByAsset(selectedAssetId) 获取

    **表单校验规则（per D-06）：**
    - command_template_id/command: 必填（根据 source 类型）
    - target_asset_id: 必填
    - run_as_system_user_id: 必填
    - 校验失败显示红色错误提示

    **状态管理：**
    - source: 'template' | 'custom' (任务来源类型)
    - selectedTemplateId: string | undefined
    - selectedAssetId: string | undefined
    - commandPreview: string (命令预览内容)

    **必填标记实现：**
    - 使用 Ant Design Form.Item 的 required 属性自动显示星号
    - 或手动在 label 后添加 Typography.Text type="danger" "*"

    **页面导出：**
