  <action>
    在 TaskCreatePage 中集成策略评估预览功能。

    **添加状态 (frontend/src/pages/TaskCreatePage.tsx):**
    - evalModalOpen: boolean (评估弹窗状态)
    - evalResult: PolicyEvaluationResponse | undefined (评估结果)
    - isBlocked: boolean (根据 evalResult.allowed 判断)
    - submitDisabled: boolean (提交按钮禁用状态)

    **添加按钮（表单底部）：**
    - 策略预览按钮：
      - text: "策略预览"
      - icon: 安全相关图标（如 SafetyOutlined）
      - onClick: 打开评估弹窗并触发评估
      - 位置：在提交按钮之前 per D-07
    - 提交按钮：
      - text: "创建任务" 或 "提交审批"（根据 approval_required 动态）
      - disabled: 当 isBlocked=true 或表单未填完时
      - per D-09

    **策略评估触发逻辑：**
    - 点击"策略预览"按钮时：
      1. 收集当前表单值：command 或 command_template_id
      2. 打开 PolicyEvaluationModal
      3. PolicyEvaluationModal 内部自动触发 useEvaluatePolicy mutation
      4. 评估完成后调用 onEvaluated callback

    **PolicyEvaluationModal 集成：**
    ```tsx
    <PolicyEvaluationModal
      open={evalModalOpen}
      command={currentCommand}
      commandTemplateId={selectedTemplateId}
      requestedRiskLevel={selectedTemplate?.risk_level}
      onClose={() => setEvalModalOpen(false)}
      onEvaluated={(result) => {
        setEvalResult(result)
        setIsBlocked(!result.allowed)
      }}
    />
    ```

    **命中策略拦截时的 UI（per D-09）：**
    - 当 evalResult.allowed === false 时：
      1. 提交按钮 disabled
      2. 显示红色警告提示（Alert type="error"）
      3. Alert 内容：
         - message: "命令被策略拦截"
         - description: evalResult.block_reason
         - 若有 matched_rules，显示匹配的规则列表

    **评估前检查：**
    - 硄保 command 或 template 已选择
    - 未填完时提示"请先填写命令或选择模板"

    提交按钮 onClick 处理：
    ```typescript
    const handleSubmit = () => {
      // 1. 检查是否有评估结果
      if (!evalResult) {
        message.warning('请先进行策略预览')
        return
      }

      // 2. 检查是否被拦截
      if (!evalResult.allowed) {
        // 已通过 UI 禁用按钮，此处不应触发
        return
      }

      // 3. 高风险任务需要确认 per D-12
      if (evalResult.final_risk_level === 'high' && evalResult.approval_required) {
        setConfirmModalOpen(true)
        return
      }

      // 4. 直接提交
      executeSubmit()
    }
    ```

    确认后提交：
    ```typescript
    const executeSubmit = () => {
      const payload: TaskCreateRequest = {
        command_template_id: selectedTemplateId,
        command: currentCommand,
        target_asset_id: formValues.target_asset_id,
        run_as_system_user_id: formValues.run_as_system_user_id,
        risk_level: evalResult.final_risk_level as 'low' | 'medium' | 'high',
      }

      createTask(payload)
    }
    ```

    useCreateTask mutation 使用：
    ```typescript
    const { mutate: createTask, isPending } = useCreateTask()

    const onSuccess = (data: TaskCreateResponse) => {
      if (data.approval_required) {
        // D-10: 跳转审批详情页
        message.success('任务已提交审批，正在跳转...')
        navigate(`/approvals/${data.approval_id}`)
      } else {
        // D-11: 显示成功 Toast（暂无任务详情页）
        message.success('任务创建成功！')
        // 可选：跳转到某个列表页或停留在当前页
        navigate('/dashboard')
      }
    }

    const onError = (error: ApiError) => {
      message.error(`创建失败：${error.message}`)
    }
    ```
