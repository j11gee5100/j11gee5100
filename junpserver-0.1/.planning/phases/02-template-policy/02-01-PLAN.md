  <action>
    创建三个 TanStack Query hooks 文件：

    1. frontend/src/hooks/useTemplates.ts
       - useTemplates(): useQuery 获取模板全量列表，path: '/templates/commands'
       - useTemplatesInfinite(): useInfiniteQuery 实现无限滚动，每页 20 条
       - useCreateTemplate(): useMutation 创建模板，POST '/templates/commands'
       - useUpdateTemplate(): useMutation 更新模板（含启停），PATCH '/templates/commands/{id}'

    2. frontend/src/hooks/usePolicies.ts
       - useBlacklist(): useQuery 获取黑名单列表，path: '/policies/command-blacklist'
       - useEvaluatePolicy(): useMutation 策略评估预览，POST '/policies/evaluate'
         - 参数: { command?: string, command_template_id?: string, requested_risk_level?: string }
         - 返回: PolicyEvaluationResponse
       - useCreateBlacklistRule(): useMutation 创建黑名单规则
       - useUpdateBlacklistRule(): useMutation 更新黑名单规则

    3. frontend/src/hooks/useGovernance.ts
       - useAuditLogs(filters: AuditFilters): useQuery 获取审计日志，path: '/governance/audits'
       - 支持 time_range 转换: '1h' -> hours=1, '24h' -> hours=24, '7d' -> hours=168

    所有 hooks 使用 @tanstack/react-query v5 API：
    - useQuery({ queryKey, queryFn })
    - useMutation({ mutationFn, onSuccess, onError })
    - useInfiniteQuery({ queryKey, queryFn, initialPageParam, getNextPageParam })
  </action>
