创建审批 hooks 文件 frontend/src/hooks/useApprovals.ts，实现以下 TanStack Query hooks：

1. approvalKeys query key factory（参考 useTemplates.ts 模式）：
   - all: ['approvals'] as const
   - pending: () => [...approvalKeys.all, 'pending'] as const
   - pendingByLevel: (level: number) => [...approvalKeys.pending(), { current_level: level }] as const
   - details: () => [...approvalKeys.all, 'detail'] as const
   - detail: (id: string) => [...approvalKeys.details(), id] as const

2. useApprovals(level: number)：
   - 调用 GET /api/v1/approvals/pending?current_level={level}
   - 返回 Approval[] 数组
   - staleTime: 30000 (30秒)

3. useApprovalDetail(approvalId: string)：
   - 调用 GET /api/v1/approvals/{approval_id}
   - 返回 Approval 对象（含 actions 时间线）
   - staleTime: 10000 (10秒，详情变更频繁)

4. useApprove() mutation：
   - 调用 POST /api/v1/approvals/{approval_id}/approve
   - 参数: { approvalId: string, comment?: string }
   - 成功后 invalidate approvalKeys.pending() 和 approvalKeys.detail(approvalId)
   - 处理 409 错误返回 { success: false, error: 'CONFLICT' }

5. useReject() mutation：
   - 调用 POST /api/v1/approvals/{approval_id}/reject
   - 参数: { approvalId: string, comment: string } (必填)
   - 成功后 invalidate 同上

6. useEscalate() mutation：
   - 调用 POST /api/v1/approvals/{approval_id}/escalate
   - 参数: { approvalId: string, comment?: string }
   - 成功后 invalidate 同上

所有 mutation 使用 useMutation + useQueryClient 模式，onSuccess 回调触发相关 queries 刷新。
