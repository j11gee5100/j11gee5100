**验证步骤：**

1. 打开浏览器访问审批中心页面（http://localhost:5173/approvals 或对应前端地址）

2. 验证页面布局（per D-01/D-02）：
   - 页面显示 L1/L2 两个 Tab
   - Tab 显示当前层级待审批数量（如"L1 审批 (5)"）
   - 点击 Tab 可以切换层级

3. 验证审批卡片（per D-03/D-04）：
   - 卡片显示 approval_id、task_id、风险等级、来源
   - 卡片显示超时状态（剩余时间或已超时标签）
   - 卡片底部有"通过"和"驳回"按钮
   - 卡片 hover 有视觉反馈
   - 点击卡片整体打开详情抽屉

4. 验证详情抽屉（per D-05/D-06/D-07）：
   - 抽屉从右侧滑出，宽度约 520px
   - 基础信息卡显示所有关键字段
   - 决策区有三个按钮：通过、驳回、升级
   - 下方有审批动作时间线
   - 时间线显示操作历史，节点颜色区分

5. 验证审批操作（per D-08/D-09/D-10/D-11/D-12）：
   - 点击"通过"按钮：
     - 弹出成功 Toast 提示"审批通过"
     - 列表自动刷新，卡片消失
   - 点击"驳回"按钮：
     - 原因输入框为空时提示"请填写驳回原因"
     - 输入原因（500字符限制，有计数）
     - 点击确认后弹出"审批已驳回"Toast
     - 列表刷新
   - 点击"升级"按钮：
     - 当 current_level >= max_level 时按钮禁用（灰色）
     - 升级后层级变化，列表刷新
   - 409 冲突场景（模拟或真实）：
     - 显示 Toast 提示"审批状态已变更，列表已刷新"
     - 列表自动刷新

6. 验证按钮禁用（per D-11/D-13）：
   - 找一个 status='approved' 或 'rejected' 或 'expired' 的审批
   - 确认所有操作按钮禁用（灰色不可点击）
   - 确认卡片显示超时标签（如已超时）

7. 验证空状态：
   - 切换到无待审批的层级
   - 显示空状态提示"当前层级无待审批任务"
