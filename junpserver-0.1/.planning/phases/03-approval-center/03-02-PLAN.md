**组件结构（参考 TemplateCard.tsx 模式）：**

```typescript
interface ApprovalCardProps {
  approval: Approval
  onApprove: (approvalId: string) => void
  onReject: (approvalId: string) => void
  onViewDetails?: (approval: Approval) => void
}
```

**Card 内容布局（per D-01 卡片式布局）：**

1. 卡片顶部区域：
   - approval_id（灰色辅助文本，卡片顶部）
   - task_id（灰色辅助文本，可 copyable）

2. 核心信息区域：
   - 来源标签（source，如 alert/manual/scheduled）
   - 风险等级徽章（使用 RiskBadge 组件，传入 risk_level）
   - 当前层级显示（Level L1/L2 等）

3. 超时状态区域（per D-04）：
   - 若 expires_at 存在：
     - 未超时：显示剩余时间（如"剩余 2h 15m"，绿色）
     - 已超时：显示超时标签（如"已超时"，红色）
   - 使用 dayjs 计算剩余时间或是否超时
   - 计算：now = dayjs(), expires = dayjs(expires_at), remaining = expires.diff(now, 'minute')

4. 操作按钮区域（卡片底部，per D-03）：
   - "通过"按钮（绿色，成功操作）
   - "驳回"按钮（红色，危险操作）
   - 按钮布局：左侧通过、右侧驳回，间距 8px
   - 使用 Ant Design Button 组件

**按钮禁用逻辑（per D-11/D-13）：**

```typescript
const isOperationDisabled = approval.status !== 'pending'
const isExpired = approval.status === 'expired' || (approval.expires_at && dayjs(approval.expires_at).isBefore(dayjs()))
```

- 若 status !== 'pending'，禁用通过/驳回按钮
- 若 status === 'expired'，卡片显示超时标签，按钮禁用
- 按钮使用 disabled={isOperationDisabled} 属性

**交互行为：**

1. 点击卡片整体 → 触发 onViewDetails(approval) 打开详情抽屉（per D-05）
2. 点击"通过"按钮 → 触发 onApprove(approval.approval_id)（D-03）
3. 点击"驳回"按钮 → 触发 onReject(approval.approval_id)（D-03）
4. 按钮点击需要 stopPropagation 阻止冒泡，避免触发卡片整体点击

**样式（延续 Phase 02 卡片风格）：**

- Card hoverable, cursor: pointer
- 边框：1px solid #f0f0f0
- 卡片内边距：padding: 16px（默认）
- 内容间距：marginBottom: 8px
- 超时标签颜色：
  - 未超时：绿色 (#52c41a)
  - 已超时：红色 (#ff4d4f)
